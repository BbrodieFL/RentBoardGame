React Game Development - Lesson 0006

Rent Rules As Functions

Your win for this lesson: know where to look when the game gives, removes, or displays rent rewards.

The Big Idea

Milestone 4 added game rules. A game rule answers a question from saved data: "is rent paid?", "how long is the streak?", or "should this undo remove the reward?" Those answers live in src/gameMath.ts.

Related source: React: Updating Objects in State .

One Rule In Plain English

export function isRentPaidForDate(activityEntries, localDate) {
  return getRentPointsForDate(activityEntries, localDate) >= dailyRentTarget;
}

Read it as: "add up the rent points for this date; rent is paid if the total reaches the target."

How Undo Uses The Rule

const nextActivityEntries =
  save.activityEntries.filter((entry) => entry.id !== entryId);

if (isRentPaidForDate(nextActivityEntries, removedEntry.localDate)) {
  keep the paid-day reward
} else {
  remove the paid-day reward
}

That is why undo can be honest. The app does not ask "was rent paid before?" It asks "after this correction, is rent still paid?"
