React Game Development - Lesson 0002

What Is a Prop?

Your win for this lesson: explain <StatCard stat={stat} /> without flinching.

The Mental Model

A prop is data a parent component gives to a child component. The official React docs say parent components pass information to child components by giving them props, and props can be ordinary values, objects, arrays, functions, or JSX.

Primary source: React: Passing Props to a Component .

Normal Function First

function greet(name) {
  return `Hello, ${name}`;
}

greet("Oliver");

name is an input. The function can use it without knowing where it came from.

React Component Version

function StatusChip({ label, value }) {
  return (
    <div>
      <span>{label}</span>
      <strong>{value}</strong>
    </div>
  );
}

<StatusChip label="Coins" value="140" />

label and value are props. The parent says, “render a status chip, and here is the data it should use.”

The Line From Your Game

{stats.map((stat) => (
  <StatCard key={stat.id} stat={stat} />
))}

Read that as: “For each stat object, render one StatCard, and hand that stat object to it using a prop named stat.” 

function StatCard({ stat }) {
  return <h3>{stat.name}</h3>;
}

Inside StatCard, stat is now available like a local variable.
