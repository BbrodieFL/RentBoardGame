React Game Development - Lesson 0001

Components, Props, and Config

Your first win: trace how one stat in src/gameConfig.ts becomes one stat card on the game screen.

The Idea

React UI is built from components: small functions that return JSX. The official React docs describe components as pieces of UI with their own logic and appearance. In this project, App is the screen, while StatCard, ActivityButton, and ProgressBar are smaller pieces inside it.

Primary source: React Quick Start. For lists specifically, keep React: Rendering Lists nearby.

The Path Through Your Code

src/gameConfig.ts
  exports stats

src/App.tsx
  imports stats
  maps stats into StatCard components
  passes each stat as a prop

StatCard
  reads stat.name, stat.color, stat.totalXp
  renders one visible stat card

Read This Tiny Slice

{stats.map((stat) => (
  <StatCard key={stat.id} stat={stat} />
))}

map means "turn each data item into a UI item." The key helps React track which item is which. The stat={stat} part is a prop: it hands one config object to one child component.

Practice

Notice that you did not edit StatCard. That is the point of config-driven UI.
