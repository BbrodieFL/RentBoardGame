Undo With Filter

Your win for this lesson: explain why undo creates a new activity list instead of editing the old one.

The Line To Understand

function handleUndo(entryId: string) {
  setActivityEntries((entries) =>
    entries.filter((entry) => entry.id !== entryId)
  );
}

The state value is an array of activity entries. Undo does not reach into that array and delete an item. Instead, it asks: "which entries should stay?" The answer becomes a new array.

Primary source: React: Updating Arrays in State .

Read Filter Out Loud

entries.filter((entry) => entry.id !== entryId)

For each entry, keep it only when its id is not the id we are undoing. The clicked entry fails the test, so it is left out of the new array.

Why React Likes This

React state should be treated as read-only. When you give React a new array, React can render from that new snapshot. Then all derived values update naturally: today's log, rent points, stat XP, and the saved localStorage value.
