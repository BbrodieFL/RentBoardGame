# Mission: React Game Development

## Why

You want to learn React by building a real local browser game that turns productive habits into visible RPG progress. The goal is not abstract React trivia; it is being able to understand and confidently change this game as each milestone adds behavior.

## Success looks like

- You can explain how the main screen is assembled from React components.
- You can trace how data in `gameConfig.ts` becomes visible UI.
- You can make small changes to JSX, props, and TypeScript types without feeling lost.
- You can participate in each milestone instead of treating the code as generated mystery.

## Constraints

- Keep lessons inside `learning/` and app code inside the normal project structure.
- Move in the milestone order from `ProjectRules.MD`.
- Keep explanations practical, short, and tied to files in this repo.

## Out of scope

- Backend systems, databases, accounts, hosting, or deployment.
- Advanced React performance topics before basic state and data flow feel comfortable.
