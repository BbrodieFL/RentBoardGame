# React Game Development Resources

## Knowledge

- [React: Quick Start](https://react.dev/learn)
  Official React introduction. Use for components, JSX, props, lists, events, and state.
- [React: Describing the UI](https://react.dev/learn/describing-the-ui)
  Official React guide for composing UI from components and rendering lists from data.
- [React: Passing Props to a Component](https://react.dev/learn/passing-props-to-a-component)
  Official React guide for passing information from parent components to child components. Use for props, destructuring props, and the idea that props are read-only snapshots.
- [React: Responding to Events](https://react.dev/learn/responding-to-events)
  Official React guide for attaching event handlers like `onClick` to JSX.
- [React: State - A Component's Memory](https://react.dev/learn/state-a-components-memory)
  Official React guide for `useState`, re-rendering, and why local variables do not preserve changing UI data.
- [React: Updating Arrays in State](https://react.dev/learn/updating-arrays-in-state)
  Official React guide for adding, replacing, and removing items from arrays stored in state.
- [MDN: Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)
  Canonical browser documentation for `localStorage` and `sessionStorage`. Use for origin-scoped browser persistence.
- [MDN: Using the Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API/Using_the_Web_Storage_API)
  Practical guide for `getItem`, `setItem`, `removeItem`, and the fact that storage keys and values are strings.
- [MDN: JSON.parse](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/parse)
  Use for converting saved JSON strings back into JavaScript values.
- [MDN: JSON.stringify](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify)
  Use for converting JavaScript values into strings before saving them.
- [Vite: Getting Started](https://vite.dev/guide/)
  Official Vite guide. Use for understanding the local dev server, build command, and React TypeScript template shape.
- [Vite: Features - TypeScript](https://vite.dev/guide/features#typescript)
  Official Vite explanation of TypeScript support and why `tsc` handles type checking separately from Vite's dev transform.

## Wisdom (Communities)

- [Reactiflux Discord](https://www.reactiflux.com/)
  Large React community for practical questions when a React behavior feels unclear.
- [Vite GitHub Discussions](https://github.com/vitejs/vite/discussions)
  Useful for Vite-specific setup and tooling questions.
