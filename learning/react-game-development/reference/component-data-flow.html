Component Data Flow

Core Pattern

config data -> parent component -> props -> child component -> JSX

In This Project

src/gameConfig.ts exports arrays like stats and quickActivities. src/App.tsx imports those arrays, maps over them, and passes each item into a smaller component as a prop.

Questions To Ask

  • Is this value project data? Put it in config.
  • Is this value calculated from other data? Derive it.
  • Is this repeated UI? Map over an array and render a component.
  • Does a child need data? Pass a prop.
