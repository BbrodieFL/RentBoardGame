Save File Boundary

The Pattern

gameSave object
  -> JSON.stringify(...)
  -> exported .json file

imported .json file
  -> JSON.parse(...)
  -> normalizeGameSave(...)
  -> gameSave object

Three Actions

  • handleExportSave: downloads the current save as JSON text.
  • handleImportSave: reads a JSON file, parses it, and normalizes it.
  • handleResetSave: asks for confirmation, then restores the default save.

Why Normalize?

Imported files are outside the app's control. Normalization keeps valid pieces, drops malformed entries, and fills in defaults for missing fields.

Project Files

  • src/App.tsx: export, import, and reset event handlers.
  • src/storage.ts: save shape, defaults, validation, and migration.
  • src/storage.test.ts: tests for loading, migration, and malformed data.
