Immutable Array Updates

The Rule

When an array is stored in React state, make a new array for each change. Do not edit the old state array in place.

Add One Item

setActivityEntries((entries) => [newEntry, ...entries]);

This creates a fresh array whose first item is newEntry, followed by everything that was already in entries.

Remove One Item

setActivityEntries((entries) =>
  entries.filter((entry) => entry.id !== entryId)
);

filter creates a fresh array containing only the entries that pass the test.

In This Game

  • Log activity: create a new array with one extra entry.
  • Undo activity: create a new array missing one entry.
  • Rent points and stat XP update because they are derived from the new array.
