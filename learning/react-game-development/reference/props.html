Props

One-Sentence Definition

A prop is data a parent component hands to a child component, like an argument passed into a function.

Shape

<ChildComponent propName={someValue} />

function ChildComponent({ propName }) {
  return <p>{propName}</p>;
}

In This Game

<StatCard stat={stat} />

function StatCard({ stat }) {
  return <h3>{stat.name}</h3>;
}

Rules Of Thumb

  • The parent chooses what value to pass.
  • The child reads the value from its props.
  • The child should not change its props.
  • Props make one component reusable with different data.
