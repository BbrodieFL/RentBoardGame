Game Rule Functions

The Pattern

saved data
  -> pure rule function
  -> answer
  -> React state update
  -> UI renders from new state

Current Rule Functions

  • getRentPointsForDate(entries, date): adds rent points for one day.
  • isRentPaidForDate(entries, date): checks whether that day reached the target.
  • recordRentPaidOnce(results, date, paidAt): adds one paid-day result if missing.
  • removeRentPaidForDate(results, date): removes a paid-day result after a correction.
  • getCurrentStreak(results, today): counts the live current streak.
  • getBestStreak(results): finds the longest historical streak.

Why This Helps

These functions do not render UI and do not touch localStorage. That makes them easier to read, test, and fix when a game rule feels wrong.
