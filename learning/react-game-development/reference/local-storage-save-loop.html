localStorage Save Loop

The Loop

Browser localStorage
  -> loadGameSave()
  -> React useState initial value
  -> UI renders saved activities

User logs or undoes activity
  -> React state changes
  -> useEffect runs
  -> saveGameSave()
  -> Browser localStorage

Why JSON?

Browser storage values are strings. Our save is an object, so we turn it into a string with JSON.stringify before saving, then turn it back into an object with JSON.parse when loading.

Origin Rule

http://127.0.0.1:5173 and http://127.0.0.1:5174 are different origins because the port is different. Different origins get different localStorage buckets.

Project Files

  • src/storage.ts: reads, writes, validates, and clears saved data.
  • src/gameTypes.ts: shared data shape for saved activity entries.
  • src/App.tsx: loads save data into state and saves state changes.
